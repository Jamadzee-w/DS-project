## Идея компании

Платформа, которая помогает небольшим производителям товаров (например, фермерских, крафтовых, экотоваров) находить оптимальных логистических партнёров для доставки своей продукции до конечных потребителей (B2C) или до точек продаж (B2B).
В основе — алгоритм, рекомендующий лучшего перевозчика по критериям: стоимость, скорость, география, отзывы.
